# DnDFox

[English README](README.md)

DnDFox добавляет прямую замену панелей в нативном Firefox Split View. Обычную
вкладку можно перетащить из панели вкладок на левую или правую часть Split View:

```text
[ A | B ]  C  D    -- перетащить C на B -->    [ A | C ]  B  D
```

Split View остаётся активным, вытесненная страница сохраняется как обычная
вкладка, а положение разделителя восстанавливается после замены.

## Требования

- Windows 10 или Windows 11.
- Firefox 156.
- Firefox должен быть хотя бы один раз запущен, чтобы профиль уже существовал.
- Для записи Autoconfig рядом с `firefox.exe` нужны права администратора.

DnDFox использует приватные browser-chrome API Firefox. Совместимость с новыми
версиями Firefox требует отдельной проверки.

## Установка одной кнопкой

1. Скачайте репозиторий через **Code → Download ZIP** или скачайте Release.
2. Полностью распакуйте архив.
3. Закройте все окна Firefox.
4. Запустите `install.cmd` и подтвердите запрос Windows UAC.
5. Запустите Firefox.

Установщик сам находит стандартную установку Firefox и профиль по умолчанию,
устанавливает зафиксированную версию `fx-autoconfig`, копирует DnDFox, очищает
startup cache и сохраняет резервные копии в:

```text
%LOCALAPPDATA%\DnDFox
```

Интернет во время установки не требуется.

## Удаление

Закройте Firefox и запустите `uninstall.cmd`. Автономная копия деинсталлятора
также сохраняется в `%LOCALAPPDATA%\DnDFox`.

Файлы, существовавшие до установки, будут восстановлены. Остальные скрипты и
данные профиля Firefox не затрагиваются.

## Нестандартные пути

Для нестандартной установки Firefox или другого профиля используйте:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\Install-DnDFox.ps1 `
  -FirefoxDirectory "D:\Apps\Firefox" `
  -ProfileDirectory "D:\FirefoxProfile"
```

Версия 1.0 устанавливается в один профиль за один раз.

## Безопасность

Autoconfig запускает код с привилегированным доступом к внутренностям Firefox.
Устанавливайте только проверенные релизы. Если обнаружена неизвестная сторонняя
конфигурация Autoconfig, установщик остановится, не перезаписывая её.
