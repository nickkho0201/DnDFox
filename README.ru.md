# DnDFox

[English README](README.md)

DnDFox добавляет прямую замену панелей в нативном Firefox Split View. Обычную
вкладку можно перетащить из панели вкладок на левую или правую часть Split View:

```text
[ A | B ]  C  D    -- перетащить C на B -->    [ A | C ]  B  D
```

Split View остаётся активным, вытесненная страница сохраняется как обычная
вкладка, а положение разделителя восстанавливается после замены.

## Требования

- Windows 10 или Windows 11.
- Firefox 156.
- Firefox должен быть хотя бы один раз запущен, чтобы профиль уже существовал.
- Для записи Autoconfig рядом с `firefox.exe` нужны права администратора.

DnDFox использует приватные browser-chrome API Firefox. Совместимость с новыми
версиями Firefox требует отдельной проверки.

## Установка одной кнопкой

1. Хотя бы один раз запустите Firefox, затем закройте все его окна. Это нужно,
   чтобы Firefox успел создать профиль, который найдёт установщик.
2. Скачайте репозиторий через **Code → Download ZIP** или скачайте Release.
3. Полностью распакуйте архив в обычную папку. Не запускайте установщик прямо
   из ZIP-архива.
4. Запустите `install.cmd` и подтвердите запрос Windows UAC.
5. Дождитесь сообщения `Installation completed successfully`.
6. Запустите Firefox и выполните быструю проверку из раздела
   [Как пользоваться](#как-пользоваться).

Установщик сам находит стандартную установку Firefox и профиль по умолчанию,
устанавливает зафиксированную версию `fx-autoconfig`, копирует DnDFox, очищает
startup cache и сохраняет резервные копии в:

```text
%LOCALAPPDATA%\DnDFox
```

Интернет во время установки не требуется.

### Проверка установки

1. Создайте Split View штатными средствами Firefox.
2. Оставьте в том же окне хотя бы одну обычную вкладку.
3. Перетащите эту вкладку на любую из двух видимых панелей Split View.

При наведении целевая панель должна подсветиться. После отпускания кнопки мыши
перетаскиваемая вкладка займёт эту панель, а вытесненная страница появится в
панели вкладок как обычная вкладка.

## Как пользоваться

DnDFox расширяет уже открытый нативный Split View, но не создаёт его сам.

1. Откройте две страницы в Firefox Split View.
2. В том же окне Firefox нажмите и удерживайте обычную вкладку, которая не
   входит в этот Split View.
3. Перетащите её из панели вкладок на содержимое левой или правой панели.
   Панель-цель получит визуальную подсветку.
4. Отпустите кнопку мыши над панелью, которую хотите заменить.

Пример:

```text
[ A | B ]  C  D    -- перетащить C на B -->    [ A | C ]  B  D
```

Split View останется активным. Вытесненная страница сохранится как фоновая
обычная вкладка рядом со своей прежней позицией, а разделитель вернётся к
предыдущему соотношению панелей. Если отпустить вкладку за пределами обеих
панелей, операция DnDFox отменится и Split View не изменится.

Принимаются только вкладки из текущего окна Firefox. Вкладка, которая уже
находится в активном Split View, не используется как источник замены.

## Как работает модуль

DnDFox — привилегированный browser-chrome-скрипт. При запуске Firefox его
загружает вложенная зафиксированная версия `fx-autoconfig`.

Во время перетаскивания модуль:

1. Запоминает активный Split View при первоначальном нажатии мыши — до того,
   как Firefox переключится на перетаскиваемую обычную вкладку.
2. Снова показывает исходный Split View, когда указатель входит в область
   браузера.
3. Определяет панель под указателем по геометрии двух встроенных браузеров и
   подсвечивает её.
4. При отпускании запоминает положение разделителя и дублирует вытесняемую
   страницу в обычную фоновую вкладку, чтобы она не потерялась.
5. Вызывает нативную операцию Firefox `replaceTab`, выбирает вставленную вкладку
   и восстанавливает положение разделителя после перестройки Split View.

Каждая операция получает собственный идентификатор. Перед изменениями модуль
проверяет, что вкладки, окно и Split View всё ещё актуальны. Состояние
перетаскивания и подсветка очищаются как после drop, так и после отмены.

Используются приватные API Firefox, а не WebExtension API, поэтому после
будущего обновления Firefox может понадобиться новая версия DnDFox.

## Решение проблем

- Если установщик не находит профиль, один раз запустите Firefox, закройте его
  и снова запустите `install.cmd`.
- Для Firefox или профиля в нестандартной папке используйте PowerShell-команду
  из следующего раздела.
- Если панель не подсвечивается, убедитесь, что исходная вкладка — обычная
  вкладка из того же окна, а нативный Split View сейчас виден.
- Диагностические сообщения выводятся в Browser Console Firefox с префиксом
  `[SplitView Drag Replace]`.

## Удаление

Закройте Firefox и запустите `uninstall.cmd`. Автономная копия деинсталлятора
также сохраняется в `%LOCALAPPDATA%\DnDFox`.

Файлы, существовавшие до установки, будут восстановлены. Остальные скрипты и
данные профиля Firefox не затрагиваются.

## Нестандартные пути

Для нестандартной установки Firefox или другого профиля используйте:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\Install-DnDFox.ps1 `
  -FirefoxDirectory "D:\Apps\Firefox" `
  -ProfileDirectory "D:\FirefoxProfile"
```

Версия 1.0 устанавливается в один профиль за один раз.

## Безопасность

Autoconfig запускает код с привилегированным доступом к внутренностям Firefox.
Устанавливайте только проверенные релизы. Если обнаружена неизвестная сторонняя
конфигурация Autoconfig, установщик остановится, не перезаписывая её.
